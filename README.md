# Notchy

Independent native macOS notch companion, built with AppKit and SwiftUI. Working app name, not a trademark clearance claim. Requires macOS 13+, Swift 5.9 and CMake. Apple Silicon is the supported local build target; Intel is not verified.

```sh
./build.sh build     # dist/Notchy.app, ad-hoc signed
./build.sh run       # build and open, no installation
./build.sh selftest  # deterministic checks, temporary storage
./build.sh dmg       # dist/Notchy.dmg with Applications link
```

CMake: `arch -arm64 /opt/homebrew/bin/brew install cmake` on an Apple Silicon Homebrew installation. The build fails if the adapter cannot be built. No Xcode upgrade, LaunchAgent, auto-installation, or automatic login registration.

## Use

Hover inside the visible shell for 150 ms to expand; leaving sooner cancels opening. Closed status stays level with the camera: actual ring at left, compact 24-hour clock at right, with no lower apron or idle media icon. Explicit minimal mode hides status. Without a camera cutout, the shell starts below the menu bar. Expanded widths follow each mode's content. The feature-title menu selects any page; side arrows and Command-Option-Left/Right step without wrapping. Horizontal trackpad gestures change one page on release; vertical scrolling stays with lists/lyrics. **Sembunyikan panel** hides only the panel and suppresses hover reopening until exit/re-entry. The menu-bar icon offers **Buka Notchy**, **Pengaturan**, and **Keluar dari Notchy**. Escape cancels task composition/editing before hiding. Keyboard open and valid file drag open immediately. Reduce Motion applies geometry directly with short opacity-only page fades. Fullscreen overlays are deliberately unsupported.

- **Musik:** controls the current system now-playing player through the bundled MediaRemote Adapter. No player-selection UI. Adapter failures have an explicit retry, never a hidden AppleScript fallback.
- **Lirik:** enable in settings before use. Title, artist, album and duration are sent to LRCLIB only after opt-in. Synced lines seek; plain lyrics do not.
- **Fokus:** 25-minute focus or 5-minute break; start, pause/resume, reset. No automatic next phase. Deadlines survive sleep and relaunch.
- **Air:** set a positive goal and serving size, record a drink or undo today's latest. History is retained across midnight. Optional reminders respect active local hours and stop at the goal.
- **Shelf:** add file/folder references through drag/drop or the file picker. Open or drag an original out; remove/clear only removes references, never files.
- **Clipboard:** off by default. When enabled, polls text once per second and keeps up to 20 distinct entries only in memory. Secret/transient/autogenerated pasteboard markers are skipped, but password-manager exclusions are not guaranteed. Disabling clears history.
- **Tugas:** completed/total summary, inline Add/Edit composer with optional due date, complete/uncomplete and delete. Drafts survive page changes; Save closes only after successful persistence. Due reminders are once-only until the due date changes.
- **Sholat:** locally calculated Kemenag-angle times, not certified mosque schedules. Jakarta is an editable preset, not detected location. `Konfirmasi lokasi` / `Lokasi & metode` opens an information popover without replacing the schedule. Confirm coordinates and timezone in Settings before reminders; reminders and explicit music pause are off by default. Undefined solar events are not invented.
- **Widgets:** current local week with dots for incomplete Notchy due tasks, today's due count and earliest due task in that week (overdue included), plus actual battery state. No Apple Calendar account or integration. AC connection is not labelled charging unless IOKit reports active charging.

## Storage and security

Tasks, water history, file bookmarks and focus state are atomically saved at `~/Library/Application Support/Notchy/state.json`, in a user-only directory. Settings use UserDefaults. Corrupt/unreadable JSON disables writes instead of overwriting the file; back up and repair it manually. Failed saves remain visible. No accounts, cloud sync, camera, Accessibility, geolocation or other apps' notification access.

Ad-hoc signing is for local use, not notarized distribution. Private MediaRemote behavior may change after macOS updates. Only normal system volume is used for reminder sounds. Typed device notices indicate actual power state and Bluetooth output names, not AirPods battery levels. Notices append below an expanded feature instead of covering its controls.
